# 2D Platformer Game with Level Editor using pygame

**COMMANDO** is a side-scrolling 2D platformer shooter game built using Python and Pygame. It includes dynamic enemy AI, collectibles, explosions, multiple levels, and a fully functional **custom level editor** to create and load your own levels.

---

## 🚀 Features

- Smooth player controls: move, jump, shoot, and throw grenades.
- Intelligent enemy AI: they patrol, detect players, and shoot.
- Various obstacles: water, platforms, walls, health/ammo/grenade boxes.
- Animated sprite system for player and enemy.
- Visual effects: explosions, screen fade transitions.
- Save/load level data with `.csv` files.
- **Level editor** to design custom levels visually.
- Simple and intuitive level selection menu.

---

## 🎮 Controls
| Action              | Key           |
| ------------------- | ------------- |
| Move Left           | A             |
| Move Right          | D             |
| Jump                | W             |
| Shoot               | SPACE         |
| Throw Grenade       | Q             |
| Escape Game         | ESC           |
| Select Level (Menu) | 1 / 2 / 3...  |
| Confirm Level Start | Click START   |
| Restart on Death    | Click RESTART |
